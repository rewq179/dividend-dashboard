# 배당 대시보드

국내 배당·분배 ETF의 **보유 현황, 배당 일정, 실현 배당, 연금 납입 한도, 금융소득 한도**를 한 화면에서 보는 개인용 도구.

👉 **[열기](https://rewq179.github.io/dividend-dashboard/)**

- **`index.html` 한 파일**이다. 서버도 빌드도 설치도 없다
- 폰에서 주소를 열고 홈 화면에 추가하면 앱처럼 쓸 수 있다

## 데이터는 어디에도 올라가지 않는다

이 페이지는 정적 HTML이고 **서버가 없다.** 화면에 뜨는 값은 전부 브라우저 안에서만 계산되며, 보유 종목이나 금액이 밖으로 나가는 경로 자체가 없다.

- 데이터는 `더보기 → 설정 → JSON 불러오기`로 **직접 넣는다**
- 넣은 데이터는 그 브라우저의 `localStorage`에만 남는다. 기기마다 한 번씩 넣어야 한다
- `JSON 내보내기`로 언제든 파일로 빼낼 수 있다. 백업과 기기 간 이동은 이 파일로 한다

### 폰에서 클라우드의 파일을 고를 때

안드로이드 선택기는 드라이브가 첫 화면에 없다. `작업 선택`에 카메라·사진만 보여도 정상이다.

```
JSON 불러오기
  └─ 작업 선택          → 사진 및 폴더
       └─ 다른 앱의 파일 탐색  ← 이 줄을 수평 스크롤
            └─ 드라이브 → 폴더 → my-holdings.json
```

## 지금은 읽기 전용이다

화면에서 종목을 추가하거나 고치는 기능이 없다. **불러온 JSON을 보여주기만 한다.** 데이터는 만든 사람이 각자 준비해야 하고, 지금은 스키마를 직접 작성하는 방법뿐이다.

계좌는 일반·연금저축·IRP 셋으로 나뉘고, 배당 예상액은 종목별 분배금 이력과 배당락 주기로 계산한다.

## 보기 설정

`더보기 → 설정`에서 켤 수 있다.

- **금액 가리기** — 화면·툴팁·차트 라벨의 금액을 `••••`로 덮는다. 비율과 수량, 막대 길이는 남으므로 흐름은 그대로 읽힌다
- **미장은 달러로** — 해외 상장 종목의 평가금액·손익·연 배당을 달러로 본다. 합계와 차트는 원화를 유지한다
